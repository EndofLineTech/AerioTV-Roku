# Guide options focus inset — 0.3.80 development candidate

`AerioTV-Roku-itn` is the PO-reported guide `*` menu visual defect. A private
target Roku capture showed the selected label starting at the same x
coordinate as the rounded selection pill, nearly touching its edge. The
native LabelList uses a focus bitmap sized to each item but exposes no
documented text-padding field.

The picker now draws a **952px** focus item inside the 1000px modal instead of
900px. A generated transparent 28px LabelList icon provides real text inset
without modifying the ContentNode title or changing spoken text. Its image
is generated by `scripts/generate-ui-assets.py` and reused by all picker rows.

On the installed target (1920x1080), private captures were inspected at the
normal size and in a disposable **120% text/high-contrast** probe. The first
and scrolled longest option both remained inside the pill with clear left
and right margins. Fifteen Down presses scrolled to the long Settings item;
OK opened Settings with usable focus in the normal app. The temporary probe
changed appearance in memory only; the normal ZIP was reinstalled. No private
media label or screenshot is committed.

With the normal app's guide `*` menu left onscreen after restoration, the PO
physically confirmed that the selected label now sits comfortably inside the
wider pill. This is the actual TV acceptance of the reported visual defect;
private captures and the 120% scripted check are supporting evidence.
