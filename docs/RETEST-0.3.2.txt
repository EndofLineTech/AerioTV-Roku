BUTTON PATHS / STARTING SCREENS
-----------------------------
Select a menu label = Up/Down to highlight it, then OK. In the horizontal
transport row, use Left/Right to highlight an action, then OK.
Bare fullscreen = playing video with app information and menus dismissed.
From guide: arrows to a live channel -> OK starts playback.
PLAYER OPTIONS: bare fullscreen -> *.
Fallback: bare fullscreen -> OK -> Up (or Down) -> Left/Right to Options -> OK.
If * fails, use the fallback for the other sections and record the failure.
GUIDE / MINI-GUIDE: bare fullscreen -> Back. Back or Play expands again.
GUIDE OPTIONS: guide -> *.
RELAUNCH: Home -> open the installed AerioTV app again.
Follow menu labels, not a fixed number of arrow presses; positions vary.
