BUTTON PATHS / STARTING SCREENS
-----------------------------
Select an item = Up/Down to its label -> OK. In the horizontal transport row,
use Left/Right to highlight an action -> OK.
Tune = from the guide, highlight a currently airing channel/program -> OK.
Bare fullscreen = playing video with app menus/info dismissed. Wait about
8 seconds for the automatic tune-in information to disappear.

PLAYER OPTIONS (known working): bare fullscreen -> OK -> Up -> Left/Right
to Options -> OK. Down instead of Up also enters transport.
STOP (short path): bare fullscreen -> OK -> Up -> Left/Right to Stop -> OK.
MINI-GUIDE: Back from bare fullscreen. Back or Play expands again.
RELAUNCH: Home -> open AerioTV Roku Preview again.

When a menu is open, Back closes its inner layer first. Do not keep pressing
Back blindly: from bare fullscreen it minimizes; in the diagnostic it exits.

------------------------------------------

profile discovery. That is a separate 20-second wait BEFORE media startup.
Time startup buffering from the player entering BUFFERING, not from an AAC
profile-discovery notice in the guide.

[  PASS   ] D01 Normal startup and ongoing picture/audio work without a retry loop.

use another channel that has shown the intermittent startup stall.
        Channel / time / first outcome: _______________________________

If media startup genuinely stalls, do not manually retune immediately.
The app permits ONE automatic local retry for a confirmed native buffering
stall, or after approximately 25 seconds still awaiting initial playback.
[  PASS   ] D02 Exactly one startup-retry notice appears; it does not repeatedly retry.
[ PASS    ] D03 The retry recovers moving picture and synchronized sound without input.
        Time to notice: __________ Time to recovered playback: ________

[  PASS   ] D04 The selected audio mode has not silently changed.

[ PASS    ] D05 Playback ends with an error rather than retrying indefinitely.
[  PASS   ] D06 A buffering-stall error describes stalled buffering, not proof of
