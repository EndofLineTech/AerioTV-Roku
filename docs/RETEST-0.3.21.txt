PREPARATION (about 15-25 minutes for the ordinary checks)
-------------------------------------------------------
- Start in the Live TV guide. '*' means the remote star button.
- Menu paths: press *, select the named item with Up/Down, then OK.
- Open details consistently with * -> Program details. OK on a current program
  may tune live instead; use the menu when this plan asks for details.
- Choose channel A with known advertised catch-up retention, and channel B known
  to have none. Use Dispatcharr's information as the comparison when available.
- Choose an ended program on A within its retention window for playback tests.
- Optional: a second viewer and an account without catch-up permission.

The channel badge is the text CATCH-UP above its name, alongside its number.
Retention appears as "Catch-up: N days (provider advertised)" in the selected
guide summary and program details. This marks channel capability, not proof that
every archive is ready. Current-program Restart and 60-minute rewind are not
enabled in this build; do not expect to find those controls.

ARCHIVE GO LIVE

[  PASS   ] GOL01 Open and dismiss archive controls

[  PASS   ] GOL02 Return from playing archive to live
Resume archive playback. Up -> Go Live -> OK.
Expected: current broadcast of the SAME channel A, normal live controls and audio
preference. The archive does not reopen or take focus afterward.

[  PASS   ] GOL03 Return from paused archive to live
Start A's archive again, pause, then Up -> Go Live -> OK.
Expected: live playback starts without inheriting the archive pause. Live program
information describes the current broadcast, not the old archived program.
Back minimizes live playback; Back or Play expands it again.

[  PASS   ] GOL04 Optional second viewer and session cleanup

Expected: the other viewer continues uninterrupted. If Dispatcharr session status

Record observed status/time; do not stop a shared channel to clear it.
