FOR EACH CASE — start with a fresh launch
---------------------------------------
1. Home -> open AerioTV Roku Preview -> tune a known-working channel.
2. Wait until video and audio are playing normally.
3. OK -> Up -> Left/Right to Options -> OK.
4. Select Fullscreen * diagnostic (temporary test).
5. Select case 7/8 or 8/8 DIRECTLY. Do not run the inset cases.
6. Confirm the banner's case number, wait one second, then press/release * once.
7. Record the menu. If it opens, Back ONCE closes it; read the banner counters.
   If nothing opens, read the counters before pressing Back.
8. Back with no menu open exits the diagnostic and restores normal Video UI flags.
