[         ] A01 Startup and basic guide regression
Launch. Verify readable text, populated guide, and no blank/black/error screen.
Confirm the installed version via Settings > General > About (should show 0.3.40).

[         ] A02 Primary navigation shapes and states (faa.14, faa.22)
Move focus to the top navigation (Up at the top of the guide). Live TV / VOD /
Settings should use icon+text capsules. Focused tab is white with dark text;
the selected tab retains cyan when focus moves away. Only the active focus owner
should show focus. Check subtle growth (1.04x), no overlap, no square edges.
Verify centered strip: 3 tabs centered in 1728px safe area (start x ≈ 648px).

[         ] A03 Group pills and sidebar (faa.20, faa.22)
Settings > Appearance > Group navigation. Check Pills, Sidebar, and Modal.
Pills have capsule ends; Sidebar uses rounded rows. Selected group is cyan;
focus follows the rounded outline. Long labels remain readable/truncate cleanly.
Count: exactly 5 pills visible when ≥5 groups exist; caption centered above strip.
Strip centered on 1920px canvas (start x ≈ 352px for 5 groups). Restore layout.

[         ] A04 Guide grid focus and EPG flag badges (faa.21, faa.23)
Navigate rows and times. Program cells stay SQUARE. The current cell has a clear
white outline (0xFFFFFEFF), including category-colored programs. Moving focus into
top/group navigation removes that outline; returning restores the current guide selection.
Check EPG flag pills: LIVE (red #FF4757), NEW (green #27AE60), PREMIERE/FINALE (purple #9B59B6).
Badges are centered vertically/horizontally in capsule (y=4, height=20). LIVE badge has
x=5 offset; others x=4. Badges do not overlap time text; time shifts right when badges present.
Episode numbers (S/E) and subtitle toggle (showSubtitles) respected.

[         ] A05 Player controls and info (faa.15)

[         ] A09 Settings rail and detail (faa.17)

to guide. Check all categories, choices, reset confirmation and long values.
Settings text uses scaled fonts (body/secondary sizes respond to textSize pref).
