BUTTON PATHS / STARTING SCREENS
-----------------------------
"Select <label>" means Up/Down to highlight that label, then OK. In the
horizontal transport row, use Left/Right to highlight an action, then OK.
Menu positions vary with account permissions and playback state, so follow
labels rather than a fixed number of arrow presses.

Guide: the channel/program grid. Select a live channel with arrows -> OK
to start playback. Bare fullscreen: playing video with all app menus and
information dismissed. If a menu is open, Back dismisses its inner layers;
Back from bare fullscreen minimizes to the guide instead.

PLAYER OPTIONS: bare fullscreen -> *.
Fallback: bare fullscreen -> OK -> Up -> Left/Right to Options -> OK.
OK -> Down -> Left/Right to Options -> OK is also supported.
Use the fallback after a failed * test so remaining tests can continue.

MINI-GUIDE: bare fullscreen -> Back. Back or Play expands it again.
GUIDE OPTIONS: from the guide or mini-guide -> *.
RELAUNCH: Home -> open the installed AerioTV app again.
