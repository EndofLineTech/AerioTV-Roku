MARKING
-------
Write PASS, FAIL, or SKIP in every result blank. SKIP is not PASS. Record the
actual screen, buttons, selected mapping, observed result, and a sanitized photo
or diagnostic filename below. Do not record passwords, API keys, server/media
URLs, serial numbers, or account identifiers.

The Remote Control page offers Player and Guide mappings only. Back remains the
fixed recovery path; Home and fullscreen * are Roku-owned. A missing test media
or capability is SKIP; do not alter shared provider/network equipment to create
a fault. Restore the original map and settings before finishing.

PREPARATION
-----------
- Confirm the actual installed version in Settings -> General -> About.
- Have a known-working live channel, a catch-up channel, a movie or episode, and
  an optional second account. A mini-player requires an active live session.

  overlay fields __________  timeout/refresh __________  TMDB __________
- In the guide: Settings -> Remote control. Player means fullscreen live playback;
  Guide means the normal populated guide. Release every held key before the next
  action. Fullscreen * must be left to Roku.
