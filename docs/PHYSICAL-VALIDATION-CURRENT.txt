PREPARATION AND HOW TO USE THIS LIST
-----------------------------------
The installed development build is 0.3.17 (commit 3b06e13). The public 0.3.8 ZIP
does not contain these changes. Check the build you are testing before starting.

Have ready:
- A known-working live channel, movie, and episode; an advertised catch-up channel.
- Your original connection details available privately before connection tests.
- An admin account for source/provider selectors; a second restricted account and
  second viewer are optional. Missing prerequisites mean SKIP, with a reason.
- A phone/camera for failures and a clock for timeouts/resume positions.

Notation: '*' is the remote star button; FF/Rew are Fast Forward/Rewind.
Each named menu item is selected with Up/Down, then OK, unless stated otherwise.
Release held buttons before the next gesture. Close inner menus/info before using
Back to minimize live playback. Movie/episode playback uses Roku's native controls;
hold-OK is the LIVE player shortcut, not a promised VOD shortcut.

Suggested order:
1. A-C: startup, caching, hold OK and presentation.
2. E-F: libraries, working-source playback, saved state and archives.
3. D, G: recovery and diagnostics; conditional faults can be SKIP.
4. H-J: optional connection/fault/account/resource checks, then restore settings.

Allow roughly 90-150 minutes for the full ordinary pass, depending on load times;
optional outages, second-account checks and the soak add time. You can stop and
resume this worksheet without repeating completed checks.
For a shorter first pass: A01-A06, B01-B06, C01-C02, E01-E04, E06, E09, E17,
F01-F04 and G01-G03. The other IDs remain pending rather than implied PASS.

CURRENT BOUNDARIES / KNOWN LIMITATIONS
-------------------------------------
- The original failing VOD provider returns upstream405, exposed as HTTP500.
  That provider is not repaired. A different source for the SAME title/episode
  passed native playback. Use Choose source version and record the visible label.
  Internal provider IDs from engineering notes are not necessarily menu labels.
- Archive FF/Rew reopens a program window at minute boundaries; it is not native
  frame-accurate scrubbing. A short buffering interval during the reopen is normal.
- Native movie resume is keyframe-granular: saved67 resumed at63.605 in the sample.
  Judge whether it returns near your actual watched position, not frame equality.
- VOD local state retains at most20 entries across progress/watchlist/hidden/watched
  state. Guide RAM retains three windows; disk metadata cache is discardable.
- Do not look for universal Restart Program, a guaranteed60-minute rewind buffer,
  multiview, DVR, alphabet jump, TMDB/person recommendations, or speed choices.
  These are not delivered by this build. External links are not inline trailers.
- No fullscreen-star interception/inset experiment needs testing. Fullscreen star
  remains Roku-owned; guide/mini-guide star remains an app menu.
- Do not deliberately overload Dispatcharr/providers or change a shared source to
  manufacture an error. Conditional checks are optional; record SKIP if unsuitable.
