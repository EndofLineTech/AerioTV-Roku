PREPARATION / PATHS
-------------------
- Have a working live channel, catch-up channel, ended archive, movie and episode.
- Optional cases need a second account/viewer, captions, alternate codecs, an AAC
  discovery wait/failure, or an ALREADY configured HTTPS/redirect endpoint.
  Missing conditions mean SKIP; do not change shared profiles or stop another TV
  simply to manufacture a fault.
- Save your original connection details privately before account/URL tests.
  Do not put passwords, API keys, playable URLs or session tokens in this file.
- From fullscreen LIVE: hold OK about one second for player options. Short OK is
  Info; OK -> Up/Down -> Options is the alternative. Fullscreen * belongs to Roku.
- From guide: * is guide options. * -> Program details opens details without the
  current-program OK shortcut immediately tuning live.
- Guide header has Live TV / VOD / Settings. Reach it with hold Left; in Sidebar,
  then Left from groups; in Pills, then Up from groups. Modal goes directly there.
- In VOD: Movies/TV Shows tabs select the library; * opens library options.
- Stream Info, Audio compatibility and Captions are in hold-OK player options.
  Scaling: hold OK -> Video scale preference -> Set this channel's source aspect;
  return to that scale menu for Fit/Fill/Stretch. Record/restore each channel's
  original aspect override. Caption mode changes Roku's system-wide setting.
- Select labels with arrows then OK. Release a held key before the next gesture.
