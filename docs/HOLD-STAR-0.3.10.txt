PATH
----
1. Home -> reopen AerioTV -> tune a working channel with picture and audio.
2. OK -> Up -> Left/Right to Options -> OK.
3. Fullscreen * diagnostic (temporary test) -> select case 9/10 or 10/10.
   Scroll down the case list to reach these new entries.
4. Check the banner number; wait one second.
5. Press and HOLD * continuously for THREE seconds, then release it.
   Do not tap repeatedly. If Roku's menu appears immediately, keep holding
   through the three seconds and record whether anything else happens.
6. If a menu is open, Back once to close it. Read the banner counters/status.
   If no menu opens, read the banner before pressing Back.
7. Back with no menu open exits the diagnostic and restores normal controls.

The app starts a one-second timer ONLY after receiving a down event. Further
down events are counted as repeats and do not restart that timer. Release
stops it. A release with no delivered down is shown as RELEASE ONLY and cannot
be called a detected hold. THRESHOLD REACHED means the app timer fired; your
physical observation is still needed to establish correct behavior.

PASS = holding opens Aerio options WITHOUT Roku's menu appearing.
