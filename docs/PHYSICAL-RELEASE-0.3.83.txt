[          ] R01 Unified Dispatcharr search

one title that matches a permitted program and a VOD title. Confirm EPG,

TV Show detail; Back returns to the same search row. Open an EPG airing; it
jumps to the permitted channel and time. Check empty query/Back/edit and next

[          ] R02 Guide group and episode polish
At first, middle and last group windows confirm >, < > and < respectively.
Focus All Channels: no dark line inside its right rounded cap. Confirm a
program with valid S/E and subtitle shows both on the subtitle line, leaving
LIVE/NEW/time readable. If you use compact density, episode remains visible
before the title. Return original guide preferences afterward.

[          ] R03 DVR visual regression (only with an authorized active item)

Rewind and Forward chevrons sit centered in their round buttons. Pause/Back
and ordinary playback should still work. SKIP if there is no suitable item;
do not create another server recording under an earlier fixture approval.

intact after a search-to-detail detour. Direct Xtream/M3U connections should
indicate the shared Dispatcharr search is unavailable rather than scanning
categories. No provider or existing recording should be altered.
