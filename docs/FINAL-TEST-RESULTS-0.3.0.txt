QUICK PATHS
-----------
Fullscreen *: AerioTV player options (Up/Down scroll all choices).
Alternate player menu: OK -> Down -> Options.
Mini-guide: * -> AerioTV player options expands the existing player.
Guide *: Guide settings, Manage groups, Collections, Favorite ordering,
Program reminders, Clock format, paging/jump and refresh/cache actions.
Group pills/sidebar: enable under Guide settings; Up from the first channel
or * -> Channel groups enters it. List fallback stays available under *.
