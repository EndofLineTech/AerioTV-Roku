BUTTON PATHS / STARTING SCREENS
-----------------------------
Select a label = Up/Down to highlight it, then OK. For horizontal transport
controls, use Left/Right to highlight the action, then OK.
Guide -> arrows to a live channel -> OK starts playback.
Bare fullscreen = playing video with information and app menus dismissed.
PLAYER OPTIONS: bare fullscreen -> *.
Fallback: bare fullscreen -> OK -> Up (or Down) -> Left/Right to Options -> OK.
If * fails, record it and use the fallback for the other sections.
MINI-GUIDE: bare fullscreen -> Back. Back or Play expands again.
GUIDE OPTIONS: guide -> *.
GROUP FOCUS: hold Left for half a second in pills/sidebar mode, from any row.
RELAUNCH: Home -> open the installed AerioTV app again.
