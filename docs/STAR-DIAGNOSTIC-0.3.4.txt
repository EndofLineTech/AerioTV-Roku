START
-----
1. Tune a working channel and wait for moving video/audio.
2. OK -> Up -> Left/Right to Options -> OK.
3. Up/Down to Fullscreen * diagnostic (temporary test) -> OK.
4. The top banner should show OPTIONS KEY TEST 1/6.

FOR EACH CASE
-------------
Wait one second after changing cases, then press physical * once and release
it. Record which menu opens.
Press Back ONCE to dismiss that menu. Read the counters in the banner.
Press/release Fast Forward to advance ONE case; Rewind goes back a case.
Do not press Back when no menu is open unless you want to exit the test.
If the banner disappears, re-enter through the START path and use Fast
Forward to reach the next case. Always verify its number before pressing *.
