# Third-party artwork attribution

## Catch-up indicator

`catchup-history.svg` is Google's Material Icons **history** icon, from
https://github.com/google/material-design-icons/blob/master/src/action/history/materialicons/24px.svg
(retrieved 2026-09-20), licensed under Apache-2.0. The path is unchanged; the fill
is changed to AerioTV teal. `catchup-history.png` is the transparent 64x64 raster
used by Roku at 28x28. License: `material-icons-LICENSE.txt` in this directory.
Regenerate with `node scripts/generate-catchup-icon.mjs /absolute/path/to/@resvg/resvg-js`
using an isolated installation of `@resvg/resvg-js` (no runtime dependency).

## AerioTV launcher and splash images

`channel-icon-fhd.png` (540x405), `channel-icon-hd.png` (290x218), and
`splash-{fhd,hd,sd}.png` (1920x1080, 1280x720, 720x480) adapt the pinned upstream
Apple TV artwork without cropping or distorting its wordmark. Copyright (C) 2026
Logan Jones and contributors; GPL-3.0-or-later. See [source provenance and
regeneration instructions](upstream/README.md) and `NOTICE.md` at the repository root.
Dimensions/manifest fields follow [Roku's manifest reference](https://developer.roku.com/dev/docs/channel-manifest.md).

## Original Roku control assets

`ui-focus-pill.png`, `ui-focus-row.png`, `ui-icon-*.png`, the corner/cutout
masks, and the transparent 28px `ui-list-inset.png` are generated by
`python3 scripts/generate-ui-assets.py`. The inset icon reserves actual
LabelList text padding in the Guide `*` picker without prefixing menu titles
with spaces; it is not a visible action icon or third-party artwork.

## TMDB

`tmdb-logo.svg` is TMDB's approved alternate short blue logo, downloaded from
https://www.themoviedb.org/assets/v4/logos/v2/blue_short-8e7b30f73a4020692ccca9c88bafe5dcb6f8a62a4c6bc55cd9ba82bb2cd95f6c.svg
on 2026-09-19. `tmdb-logo.png` is a rasterized copy for Roku's Poster node.
TMDB owns this mark; its use follows https://www.themoviedb.org/about/logos-attribution
and is separate from the application's code license. It appears with the required
non-endorsement text when optional TMDB fallback supplies artwork.
